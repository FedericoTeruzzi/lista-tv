# Lista TV

Lista personale di canali italiani gratuiti per TiViMate.

**Link da usare in TiViMate:**

```
https://raw.githubusercontent.com/FedericoTeruzzi/lista-tv/main/lista-tv.m3u
```

## Come è organizzata

- **Numeri classici del digitale terrestre** (1 Rai 1, 2 Rai 2, 5 Canale 5, 17 Telecolor…). Numerazione nazionale aggiornata a settembre 2026, locali per la Lombardia.
- **Riserve:** prima riserva su 500 + numero (501 = Rai 1), seconda su 600 + numero dove disponibile.
- **Guida TV:** epgshare01, Italia.

## Verifica

Link controllati il 23/10/2026 da una rete italiana: playlist e primo pezzo di video scaricati, molti anche riprodotti. Esclusi link scaduti, protetti da DRM o ritrasmissioni non ufficiali.

Fonti di partenza: chillIPTV, Free-TV/IPTV, iptv_italia, iptv-org.
